# ZK Medical Referral System

This repository contains the Zero-Knowledge Medical Referral System.

## Project Structure
- `backend/`: Node.js + Express server for referral storage and retrieval.
- `Hack-Buzz/`: Frontend or other project components.

## Getting Started

### Backend
To run the backend:
1. Navigate to the `backend` directory.
2. Install dependencies: `npm install`
3. Start the server: `npm start`

For detailed API documentation and tests, see [backend/README.md](./backend/README.md).
